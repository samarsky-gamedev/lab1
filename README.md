# Лабораторная работа № 1

Вариант 12: университет. Python, ООП, исключения, JSON и XML.

Пять основных классов: `Person`, `Student`, `Teacher`, `Course`, `University`.
Студент относится к группе, преподаватель — к кафедре, курс связан
с преподавателем через `teacher_id`. ID уникальны внутри каждого раздела.

## Запуск

```console
python main.py
```

Весь код программы находится в `main.py`: ровно 200 строк, включая пустые
строки и комментарии. Используется только стандартная библиотека Python 3.10+.
Пять классов предметной области и отдельное собственное исключение
`UniversityError`. Других Python-файлов для запуска не требуется.

Меню: **1** — список, **2** — добавить, **3** — изменить, **4** — удалить,
**5** — сохранить, **6** — загрузить, **0** — выйти.
Для действий 1–4 выберите раздел: студенты, преподаватели или курсы.
При изменении введите все поля записи заново; ID остаётся прежним.

Для знакомства выберите **6** и укажите `examples/university.json` или
`examples/university.xml`. Запускайте программу из папки репозитория.
Оба файла содержат одинаковые демонстрационные данные.

Сохраняйте свою работу в `data.json` или `data.xml` через пункт **5**.
Автоматического сохранения нет. Успешная загрузка заменяет текущие данные;
неудачная оставляет их без изменений. Можно вводить и абсолютный путь.

Преподавателя следует добавить до курса. Нельзя удалить преподавателя,
пока на него ссылается хотя бы один курс. Студенты учитываются по группам;
зачисление на курсы и оценки в этой модели не предусмотрены.

## Этапы Git

1. Модель предметной области, UML и CRUD.
2. Консольное меню и обработка ошибок.
3. Один файл до 200 строк, чтение и запись JSON/XML, проверки.
4. Отчёт, инструкция и объяснение кода.
